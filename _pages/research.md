## Primary Research Areas

### Online Machine Learning
Developing adaptive learning algorithms that evolve with streaming IoT data — ensemble methods, incremental learning, and real-time model updates without catastrophic forgetting.

### Concept Drift Detection
Detecting and adapting to changes in data distributions over time, a critical challenge in IoT environments where attack patterns evolve continuously.

### Deep Learning for Security
Applying Bi-LSTMs, CNNs, and tree-based convolutional networks for anomaly detection and intrusion classification in IoT networks.

### Internet of Things (IoT) Security
End-to-end security for IoT ecosystems — from lightweight attack detection on edge devices to scalable analytics using Apache Spark and complex event processing.
