How to Upload Materials

  1. Add your file (PDF, PPTX, ZIP, etc.) to the assets/materials/ folder in this repository.
  2. Open _data/teaching_materials.yml and add or update an entry with the file path.
  3. Set placeholder: false when the material is ready to publish.
  4. Commit and push — GitHub Pages will deploy the file automatically.

For large video files, host externally (YouTube, Google Drive) and use the url field instead of file.
