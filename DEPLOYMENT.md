# Deploy at https://sanket-mishrax.github.io/

## Step 1 — Rename the repository (required)

1. Open **https://github.com/sanket-mishrax/sanketmishra.github.io/settings**
2. Under **Repository name**, change `sanketmishra.github.io` → **`sanket-mishrax.github.io`**
3. Click **Rename**

GitHub will automatically serve the site at **https://sanket-mishrax.github.io/**

## Step 2 — Set Pages source

1. Go to **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **`gh-pages`** / **`/ (root)`**
4. Save

## Step 3 — Wait

The deploy workflow runs on every push to `master`. Allow 2–5 minutes after the rename for the site to update.
