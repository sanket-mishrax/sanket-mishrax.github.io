# Deploy at https://sanket-mishrax.github.io/

## Step 1 — Set Pages source

1. Open the repository: **https://github.com/sanket-mishrax/sanket-mishrax.github.io**
2. Go to **Settings → Pages**
3. Source: **Deploy from a branch**
4. Branch: **`gh-pages`** / **`/ (root)`**
5. Save

## Step 2 — Wait

The deploy workflow runs on every push to `master`. Allow a few minutes after a push for the site to update.
